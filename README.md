# VoteHub — Plataforma de Salas de Votação

## 📌 Sobre o projeto

O **VoteHub** é uma aplicação web desenvolvida como entregável para o processo de treinamento (Trainee) da Atria Jr..
O objetivo principal do projeto é demonstrar conhecimentos em desenvolvimento **Full Stack**, envolvendo integração entre frontend e backend, manipulação de banco de dados, consumo de APIs e implementação de operações CRUD.

A aplicação funciona como um **hub de salas de votação**, permitindo que usuários possam:

* Criar salas de votação;
* Entrar em salas existentes;
* Participar de votações em tempo real;
* Gerenciar informações relacionadas às salas e votos.

Além do funcionamento da plataforma em si, o projeto foi pensado como uma forma prática de aplicar conceitos fundamentais de desenvolvimento web moderno.
